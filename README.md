# กิจกรรมเรียนซ่อมเสริมและสอบแก้ตัว ครั้งที่ 1 และครั้งที่ 2 · ภาคเรียนที่ 1 ปีการศึกษา 2569

เว็บไซต์สารสนเทศสำหรับนักเรียน ครูประจำวิชา และครูที่ปรึกษา โรงเรียนพรตพิทยพยัต
จัดทำโดยกลุ่มงานวัดผลและประเมินผล กลุ่มบริหารวิชาการ
ตามคำสั่งโรงเรียนพรตพิทยพยัต ที่ 239/2569 และประกาศโรงเรียนพรตพิทยพยัต ลงวันที่ 21 กันยายน 2569

## การนำขึ้น GitHub Pages

เว็บไซต์นี้เป็น static site ล้วน ไม่ต้องติดตั้งอะไรเพิ่ม

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ root ของ repo
2. ไปที่ **Settings → Pages** เลือก **Source: Deploy from a branch** · branch `main` · folder `/ (root)`
3. รอสักครู่ เว็บไซต์จะขึ้นที่ `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`

ไฟล์ `.nojekyll` มีไว้เพื่อให้ GitHub Pages ไม่ประมวลผลด้วย Jekyll (จำเป็นเมื่อมีชื่อไฟล์ภาษาไทยหรือขึ้นต้นด้วย `_`)

เปิดจากเครื่องโดยตรงก็ได้ — ดับเบิลคลิก `index.html` ได้เลย เพราะข้อมูลเก็บเป็นไฟล์ `.js` ไม่ได้ใช้ `fetch`

## โครงสร้างไฟล์

```
index.html              หน้าเว็บหลัก (single page application)
assets/style.css        สไตล์ทั้งหมด
assets/app.js           ตรรกะการแสดงผลและการค้นหา
data/data.js            ข้อมูลทั้งหมด (window.PROT)
photos/students/*.jpg   รูปนักเรียน ตั้งชื่อตามรหัสประจำตัว
photos/teachers/*.jpg   รูปครู
info/*.jpg              อินโฟกราฟิกประกาศและตารางปฏิบัติหน้าที่
```

## หน้าต่าง ๆ ในเว็บไซต์

| หน้า | ใช้ทำอะไร |
|---|---|
| ภาพรวม | ตัวเลขรวมทั้งโรงเรียนและรายระดับชั้น กำหนดการ ปริมาณงานของแต่ละกลุ่มสาระฯ (ไม่แสดงรายห้อง รายวิชา หรือรายบุคคล) |
| นักเรียน | ตรวจสอบรายบุคคล — กรอกรหัสประจำตัว 5 หลักให้ตรง จึงจะเห็นข้อมูลของตนเอง ไม่มีการแสดงรายชื่อนักเรียนรวม |
| ครูประจำวิชา | รายชื่อครูพร้อมรูป แยกตามกลุ่มสาระฯ (ไม่แสดงจำนวนนักเรียน) กดปุ่ม “ดูรายละเอียด” ที่ชื่อของตนเองเพื่อเปิดรายชื่อนักเรียนในรายวิชาของตน |
| ครูที่ปรึกษา | เลือกห้องของตนเองจากรายการ แล้วเปิดใบกำกับติดตามของห้อง |
| ตารางรอบ | ตารางปฏิบัติหน้าที่ครั้งที่ 1 และครั้งที่ 2 พร้อมจำนวนนักเรียนที่คาดว่าจะเข้าพบแต่ละสถานี |
| คำชี้แจง | อินโฟกราฟิกสำหรับนักเรียนและครู วิธีดูผลการเรียนในแอป PROT Student Care และที่มาของข้อมูล |

ช่องค้นหาที่มุมขวาบน ค้นได้จากรหัสนักเรียน 5 หลัก (ต้องตรงทั้งรหัส ไม่ค้นจากชื่อนักเรียน) ชื่อครู และห้องเรียน

### หลักการแสดงข้อมูล

เว็บไซต์ออกแบบให้ **แสดงข้อมูลเป็นรายบุคคลเท่านั้น** เพื่อไม่ให้นักเรียนหรือครูรู้สึกถูกประจาน
ไม่มีหน้าใดแสดงรายชื่อนักเรียนทั้งหมด ไม่มีตารางเปรียบเทียบจำนวนนักเรียนระหว่างครูหรือระหว่างห้อง
และรหัสอ้างอิงของครูในลิงก์เรียงตามชื่อ ไม่ได้เรียงตามจำนวนนักเรียน

ข้อจำกัด: เว็บไซต์นี้เป็นเว็บแบบ static ไม่มีระบบล็อกอิน ผู้ที่รู้รหัสประจำตัวของนักเรียนคนอื่น
หรือเลือกชื่อครูท่านอื่น ยังเปิดดูข้อมูลได้ และผู้ที่มีความรู้ทางเทคนิคสามารถเปิดไฟล์ `data/data.js` ดูได้โดยตรง

## ที่มาของข้อมูล

* ผลการเรียน — ระบบ PROT CARE รายงาน `SRR0641 รายงานผลการเรียนที่ยังสอบไม่ผ่าน` (ไล่ครบทุกหน้า ทุกห้อง)
  ตรวจสอบซ้ำกับ `ADF0601 ผลการเรียนรายบุคคล` ของนักเรียนทั้ง 3,085 คน และรายงานสรุป `SRR0641_3`
* รายชื่อและรูปนักเรียน — `SRR0182 บัญชีรายชื่อนักเรียน` ปีการศึกษา 2569 ภาคเรียนที่ 1
* รูปครูและกลุ่มสาระฯ — ทำเนียบบุคลากรโรงเรียนพรตพิทยพยัต ปีการศึกษา 2569
* วัน เวลา สถานที่ และรายชื่อคณะกรรมการ — คำสั่งโรงเรียนพรตพิทยพยัต ที่ 239/2569

## วันและเวลาที่ดึงข้อมูล

เว็บไซต์แสดง **วันและเวลาที่ดึงข้อมูลจากระบบจริง** ไว้ 4 จุด คือ แถบสีเหลืองใต้เมนู หน้าภาพรวม
หน้าคำชี้แจง และท้ายเว็บ รวมถึงหัวกระดาษเวลาสั่งพิมพ์ ข้อมูลชุดปัจจุบันดึงเมื่อ
**วันอังคารที่ 22 กันยายน 2569 เวลา 17.49 น.**

ค่านี้มาจากไฟล์ `data/data.js` ที่ฟิลด์ `meta.asOf` (พร้อมฟิลด์ย่อย `asOfDate` `asOfTime` และ
`asOfISO` ซึ่งเป็นเวลามาตรฐานสากล) เมื่อปรับปรุงข้อมูลผลการเรียนชุดใหม่ ให้สร้าง `data/data.js`
ทับไฟล์เดิม ทุกหน้าจะเปลี่ยนวันและเวลาตามอัตโนมัติ ไม่ต้องแก้ `index.html` หรือ `assets/app.js`

หากต้องการแก้เฉพาะข้อความวันเวลาโดยไม่สร้างไฟล์ใหม่ทั้งชุด ให้เปิด `data/data.js` แล้วค้นหา
`"asOf":` ซึ่งอยู่ช่วงต้นไฟล์ แล้วแก้ข้อความในเครื่องหมายคำพูด เช่น
`"asOf":"วันพุธที่ 30 กันยายน 2569 เวลา 09.15 น."`

## ข้อควรระวังเรื่องข้อมูลส่วนบุคคล

เว็บไซต์นี้มีชื่อ รูปถ่าย และผลการเรียนที่ไม่ผ่านของนักเรียนรายบุคคล
หากเผยแพร่เป็น repository สาธารณะ ข้อมูลเหล่านี้จะเปิดให้บุคคลทั่วไปเข้าถึงได้
แนะนำให้ใช้ **private repository** หรือจำกัดการเข้าถึงเฉพาะผู้เกี่ยวข้อง
ในหน้าเว็บได้ใส่ `<meta name="robots" content="noindex, nofollow">` ไว้แล้ว เพื่อไม่ให้เครื่องมือค้นหาเก็บข้อมูลหน้านี้
