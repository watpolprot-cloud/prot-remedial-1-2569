# สรุปการแก้ไขผลการเรียน ครั้งที่ 1 และครั้งที่ 2 · ภาคเรียนที่ 1 ปีการศึกษา 2569

เว็บไซต์สรุปปิดงานการแก้ไขผลการเรียน (เรียนซ่อมเสริมและสอบแก้ตัว) โรงเรียนพรตพิทยพยัต
จัดทำโดยทีมงานวัดผลและประเมินผล กลุ่มบริหารวิชาการ · ปิดงานเมื่อ 2 พฤศจิกายน 2569
อ้างอิงคำสั่งโรงเรียนพรตพิทยพยัต ที่ 239/2569 และที่ 254/2569

## โครงสร้างไฟล์ (ฉบับสรุปปิดงาน)

```
index.html          หน้าเว็บหลัก 6 เมนู: สรุปผล · ตรวจผลรายบุคคล · ลำดับการดำเนินงาน · คำสั่งและประกาศ · ช่องทางประกาศผล · คลังเอกสาร
assets/final.js     ตรรกะทุกหน้า
assets/final.css    สไตล์เพิ่มเติม (ใช้ร่วมกับ assets/style.css)
data/final.js       ข้อมูล window.PROTF สร้างด้วย prot_site_builder/build_final_data.py ห้ามแก้มือ · ไม่มีชื่อและรูปนักเรียน
docs/               คำสั่ง ประกาศ (PDF) อินโฟกราฟิกครั้งที่ 2 ภาพรายงานผลการดำเนินงาน และ docs/records/ แบบบันทึกครั้งที่ 2 ฉบับสแกน 7 ชุด
info/               อินโฟกราฟิกครั้งที่ 1
```

เปิดจากเครื่องโดยตรงได้ ดับเบิลคลิก `index.html` เพราะข้อมูลเก็บเป็นไฟล์ `.js` ไม่ได้ใช้ `fetch`

## บันทึกการดำเนินการในระบบ SGS (เพิ่ม 3 พ.ย. 2569)

- เมนู "บันทึกการดำเนินการ SGS" (`#/sgslog`) อ่านข้อมูลจาก `data/sgslog.js` (window.PROTLOG) แก้มือได้
- ข้อตกลง: ทุกครั้งที่แชตอื่นรายงานการแก้ข้อมูลใน SGS (โฟลเดอร์ "รายงานจากแชตอื่น") ให้เพิ่มรายการใน `phases` ของ `data/sgslog.js` และปรับ `updated`
- ข้อความใน `phases` / `pending` ห้ามมีชื่อ เลขประจำตัว หรือผลรายคนของนักเรียน ใช้จำนวนรายการเท่านั้น
- รายการที่แก้หลังสร้าง `data/final.js` ใส่ใน `post` [เลขประจำตัว, รหัสวิชา, ผลเดิม, ผลใหม่, วันที่] หน้าตรวจผลรายบุคคลจะแสดงเป็น "แก้ไขเพิ่มเติม" (ไม่รวมในตัวเลขหน้าสรุปผล)

## ความเป็นส่วนตัว

- หน้าตรวจผลรายบุคคลแสดงผลเมื่อกรอกเลขประจำตัว 5 หลักตรงเท่านั้น ไม่มีรายชื่อรวม ไม่มีชื่อนักเรียน
- เว็บเป็น static ไม่มีล็อกอิน มีแท็ก `meta robots noindex`
- ครูนพพลให้คงไฟล์เดิม (data.js, data2.js, app.js, contacts.js, photos/) และนำแบบบันทึกฉบับสแกนขึ้นไว้เป็นร่องรอยการดำเนินงาน (สั่ง 1 พ.ย. 2569)

## การนำขึ้น GitHub Pages

เว็บไซต์นี้เป็น static site ล้วน ไม่ต้องติดตั้งอะไรเพิ่ม

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ root ของ repo
2. ไปที่ **Settings → Pages** เลือก **Source: Deploy from a branch** · branch `main` · folder `/ (root)`
3. รอสักครู่ เว็บไซต์จะขึ้นที่ `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`

ไฟล์ `.nojekyll` มีไว้เพื่อให้ GitHub Pages ไม่ประมวลผลด้วย Jekyll (จำเป็นเมื่อมีชื่อไฟล์ภาษาไทยหรือขึ้นต้นด้วย `_`)

เปิดจากเครื่องโดยตรงก็ได้ — ดับเบิลคลิก `index.html` ได้เลย เพราะข้อมูลเก็บเป็นไฟล์ `.js` ไม่ได้ใช้ `fetch`

## โครงสร้างไฟล์

```
index.html              หน้าเว็บหลัก (single page application)
assets/style.css        สไตล์ทั้งหมด
assets/app.js           ตรรกะการแสดงผลและการค้นหา
data/data.js            ข้อมูลทั้งหมด (window.PROT)
data/contacts.js        ช่องทางติดต่อออนไลน์ของครูประจำวิชา (window.PROT_CONTACTS) แก้ไฟล์นี้ไฟล์เดียวเมื่อได้ข้อมูลจากกลุ่มสาระฯ
photos/students/*.jpg   รูปนักเรียน ตั้งชื่อตามรหัสประจำตัว
photos/teachers/*.jpg   รูปครู

```

## หน้าต่าง ๆ ในเว็บไซต์

| หน้า | ใช้ทำอะไร |
|---|---|
| ภาพรวม | ตัวเลขรวมทั้งโรงเรียนและรายระดับชั้น กำหนดการ ปริมาณงานของแต่ละกลุ่มสาระฯ (ไม่แสดงรายห้อง รายวิชา หรือรายบุคคล) |
| นักเรียน | ตรวจสอบรายบุคคล — กรอกรหัสประจำตัว 5 หลักให้ตรง จึงจะเห็นข้อมูลของตนเอง ไม่มีการแสดงรายชื่อนักเรียนรวม |
| ครูประจำวิชา | รายชื่อครูพร้อมรูป แยกตามกลุ่มสาระฯ (ไม่แสดงจำนวนนักเรียน) กดปุ่ม “ดูรายละเอียด” ที่ชื่อของตนเองเพื่อเปิดรายชื่อนักเรียนในรายวิชาของตน |
| ครูที่ปรึกษา | เลือกห้องของตนเองจากรายการ แล้วเปิดใบกำกับติดตามของห้อง |
| ปฏิทิน | ปฏิทินการแก้ไขผลการเรียนแบบออนไลน์ (ปรับเนื่องจากสถานการณ์น้ำท่วม ตั้งแต่ 28 ก.ย. 2569) รายการที่ยกเลิกหรือเลื่อน และรายการที่ดำเนินการแล้ว |
| คำชี้แจง | อินโฟกราฟิกสำหรับนักเรียนและครู วิธีดูผลการเรียนในแอป PROT Student Care และที่มาของข้อมูล |

ช่องค้นหาที่มุมขวาบน ค้นได้จากรหัสนักเรียน 5 หลัก (ต้องตรงทั้งรหัส ไม่ค้นจากชื่อนักเรียน) ชื่อครู และห้องเรียน

### หลักการแสดงข้อมูล

เว็บไซต์ออกแบบให้ **แสดงข้อมูลเป็นรายบุคคลเท่านั้น** เพื่อไม่ให้นักเรียนหรือครูรู้สึกถูกประจาน
ไม่มีหน้าใดแสดงรายชื่อนักเรียนทั้งหมด ไม่มีตารางเปรียบเทียบจำนวนนักเรียนระหว่างครูหรือระหว่างห้อง
และรหัสอ้างอิงของครูในลิงก์เรียงตามชื่อ ไม่ได้เรียงตามจำนวนนักเรียน

ข้อจำกัด: เว็บไซต์นี้เป็นเว็บแบบ static ไม่มีระบบล็อกอิน ผู้ที่รู้รหัสประจำตัวของนักเรียนคนอื่น
หรือเลือกชื่อครูท่านอื่น ยังเปิดดูข้อมูลได้ และผู้ที่มีความรู้ทางเทคนิคสามารถเปิดไฟล์ `data/data.js` ดูได้โดยตรง

## ที่มาของข้อมูล

* ผลการเรียน — ตั้งแต่ 23 กันยายน 2569 ใช้ไฟล์ Excel “เช็คเกรด” ที่ส่งออกจากระบบ PROT CARE
  เมนู “รายงานผลการเรียนแยกตามระดับชั้น” ครบ 6 ระดับชั้น (ข้อมูลชุดแรกวันที่ 22 กันยายน 2569 ดึงจากรายงาน SRR0641 โดยตรง)
* รายการที่แก้ไขผ่านแล้ว — เทียบกับผลการเรียน ณ วันประกาศผล (22 กันยายน 2569 เวลา 17.49 น.)
* รายชื่อและรูปนักเรียน — `SRR0182 บัญชีรายชื่อนักเรียน` ปีการศึกษา 2569 ภาคเรียนที่ 1
* รูปครูและกลุ่มสาระฯ — ทำเนียบบุคลากรโรงเรียนพรตพิทยพยัต ปีการศึกษา 2569
* วัน เวลา สถานที่ และรายชื่อคณะกรรมการ — คำสั่งโรงเรียนพรตพิทยพยัต ที่ 239/2569

## การอัปเดตข้อมูลผลการเรียน

ส่งไฟล์ Excel “เช็คเกรด” ชุดใหม่ แล้วสร้าง `data/data.js` ใหม่ด้วยสคริปต์ในโฟลเดอร์ `prot_site_builder`
(อยู่นอก repo นี้) หน้าเว็บทุกหน้าจะเปลี่ยนตามอัตโนมัติ ไม่ต้องแก้ `index.html` หรือ `assets/app.js`

* ผลการเรียนปัจจุบัน = คอลัมน์ “ผลการเรียน แก้ไข” ถ้ามีค่า มิฉะนั้นใช้คอลัมน์ “ผลการเรียน”
* รายวิชาที่เคยไม่ผ่านแต่ตอนนี้ผ่านแล้ว จะย้ายไปแสดงเป็น “แก้ไขผ่านแล้ว” ในหน้าของนักเรียน ครูประจำวิชา และครูที่ปรึกษา
* วันเวลาของข้อมูล = เวลาในชื่อไฟล์ที่ส่งออกจากระบบล่าสุด แสดงที่แถบสีเหลืองใต้เมนู หน้าภาพรวม หน้าคำชี้แจง ท้ายเว็บ และหัวกระดาษเวลาพิมพ์

## การเปลี่ยนแปลงเนื่องจากสถานการณ์น้ำท่วม (ตั้งแต่ 28 กันยายน 2569)

* แก้ไขผลการเรียนแบบออนไลน์ ครั้งที่ 1 (ต่อ) ถึงวันพุธที่ 30 กันยายน 2569 เวลา 16.00 น. ประกาศผลวันศุกร์ที่ 2 ตุลาคม 2569 เวลา 09.00 น.
* ครั้งที่ 2 (ห้อง 122–125) เลื่อนไปภาคเรียนที่ 2 · รอบที่ 3 วันที่ 28 ก.ย. และประกาศผลวันที่ 29 ก.ย. ยกเลิก
* ข้อมูลรอบและห้องเดิมใน `data/data.js` ยังอยู่ แต่เว็บไม่แสดงแล้ว (ปฏิทินใหม่อยู่ใน `assets/app.js` ตัวแปร `NEWCAL`)
* ช่องทางติดต่อออนไลน์ของครู เติมใน `data/contacts.js` ใส่ข้อความหลังชื่อครู ถ้าว่างเว็บจะแสดงว่า “ช่องทางออนไลน์เดิมที่ใช้ติดต่อครูตลอดภาคเรียน”

## ข้อควรระวังเรื่องข้อมูลส่วนบุคคล

เว็บไซต์นี้มีชื่อ รูปถ่าย และผลการเรียนที่ไม่ผ่านของนักเรียนรายบุคคล
หากเผยแพร่เป็น repository สาธารณะ ข้อมูลเหล่านี้จะเปิดให้บุคคลทั่วไปเข้าถึงได้
แนะนำให้ใช้ **private repository** หรือจำกัดการเข้าถึงเฉพาะผู้เกี่ยวข้อง
ในหน้าเว็บได้ใส่ `<meta name="robots" content="noindex, nofollow">` ไว้แล้ว เพื่อไม่ให้เครื่องมือค้นหาเก็บข้อมูลหน้านี้
